# Deprecated integration note

The former Intelligence Router integration has been superseded by the independent WHAPPNUS AI Orchestrator. Do not use the legacy `WHAPPNUS_ROUTER_URL` or `WHAPPNUS_ROUTER_API_KEY` for new AI completion requests. The current contract, environment variables, tenant HMAC headers, multimodal payloads and worker authentication are documented in [`WHAPPNUS_AI_ORCHESTRATOR_INTEGRATION.md`](./WHAPPNUS_AI_ORCHESTRATOR_INTEGRATION.md).
